## Run Locally (Next.js)

**Prerequisites:** Node.js 20+

1. Install dependencies:
   `npm install`
2. Provide a Gemini API key by setting `GEMINI_API_KEY` in [.env.local](.env.local)
3. Start the development server:
   `npm run dev`

## Build & Deploy

- `npm run build` — compile the production build with Next.js.
- `npm start` — serve the compiled output (requires `npm run build` first).
